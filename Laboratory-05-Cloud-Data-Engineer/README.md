# Laboratory 05 – Cloud Data Engineer

## Mission Overview

This laboratory focuses on cloud object storage and the deployment of an S3-compatible storage server using MinIO. The goal is to understand different types of cloud storage and practice deploying and managing object storage using Docker.

## Objectives

* Differentiate between Block, File, and Object Storage.
* Deploy an S3-compatible Object Storage server using Docker.
* Access a cloud service through a web interface and port forwarding.
* Create and manage a storage bucket.
* Upload an object to cloud storage.
* Document cloud storage operations using Markdown.

## Tools Used

* KillerCoda Ubuntu Playground
* Docker
* MinIO
* GitHub
* Web Browser
* Linux Command Line

## Skills Learned

* Understanding the differences between Block, File, and Object Storage.
* Using Docker to deploy cloud services.
* Working with Docker environment variables.
* Understanding port mapping.
* Using Linux commands to manage containers.
* Understanding the purpose of object storage and buckets.
